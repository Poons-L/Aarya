# Re.Me v1.2 Release Notes

## New Features

### Quick Actions Integration Suite

Added a comprehensive Quick Actions section to the Contact Detail screen with five powerful integrations:

#### 1. Send Email
- Opens default mail client with pre-addressed email
- Pre-fills subject line with "Following up"
- Includes personalized greeting using contact's first name
- Button disabled/greyed out if contact has no email address
- Uses mailto: link for universal compatibility

#### 2. View LinkedIn
- Opens contact's LinkedIn profile in new tab
- Shows "No LinkedIn saved" when URL is missing
- Button greyed out if no LinkedIn URL configured
- One-tap access to professional network

#### 3. Schedule Meeting
- Creates Google Calendar invite with one click
- Pre-fills meeting title with contact's name
- Automatically adds contact as attendee (if email available)
- Opens in new tab for easy editing
- Works with all calendar apps that support Google Calendar format

#### 4. Export to CRM
- Expandable dropdown with two CRM options
- **HubSpot Export**:
  - Generates HubSpot-compatible CSV format
  - Includes: First Name, Last Name, Email, Phone, Company, Job Title, LinkedIn URL
  - Instant download with contact name in filename
  - Ready for HubSpot import tool

- **Salesforce Export**:
  - Generates Salesforce-compatible CSV format
  - Includes: First Name, Last Name, Email, Phone, Title, Company, Description, Lead Source
  - Combines notes, met_at, and met_date into Description field
  - Uses met_at as Lead Source (defaults to "Networking")
  - Instant download with contact name in filename

#### 5. Save as Contact
- Downloads vCard (.vcf) file with all contact details
- Compatible with:
  - iOS/Android phone contacts
  - Outlook
  - Apple Contacts
  - Google Contacts
  - Any vCard 3.0 compatible app
- Includes: Name, Company, Title, Email, Phone, LinkedIn URL, Notes
- Instant download ready to import

### Design & UX
- All buttons feature appropriate icons (Send, ExternalLink, CalendarPlus, Download, User)
- Color-coded gradients:
  - Blue for email/LinkedIn
  - Green for meetings
  - Purple for CRM export
  - Orange/amber for vCard
- Disabled states clearly indicate missing data
- Smooth expand/collapse animation for CRM dropdown
- Consistent with app's orange/gradient brand theme

## Technical Details

### New Utilities
- `contactExport.ts`: Comprehensive export utility functions
  - `generateVCard()`: Creates vCard 3.0 format
  - `generateHubSpotCSV()`: HubSpot-compatible CSV
  - `generateSalesforceCSV()`: Salesforce-compatible CSV
  - `downloadCSV()`: Handles CSV file downloads
  - `downloadVCard()`: Handles vCard file downloads
  - `createMailtoLink()`: Generates mailto URLs with params
  - `createCalendarEvent()`: Creates Google Calendar URLs

### Standards Compliance
- vCard 3.0 format for maximum compatibility
- CSV exports follow CRM-specific field mappings
- Proper CSV escaping for special characters
- URL encoding for mailto and calendar links
