# Re.Me v1.3 Release Notes

Completion pass: finishes the screens that were placeholders and fixes bugs found in an audit of the live app.

## New

- **Delete a contact** from the contact detail header (with confirmation). Linked reminders are kept; their contact link is cleared.
- **Delete a reminder** from a reminder card's Actions menu (with confirmation).
- **Profile → Notifications**: opt-in browser alerts when a reminder comes due while the app is open. A backlog (e.g. right after enabling) is grouped into one notification.
- **Profile → Privacy & Data**: explains how data is stored and processed (OpenAI for AI features) and adds **Export my data** (JSON of profile, contacts, reminders).
- **Profile → About**: what the app does, version, link to feedback.
- **Welcome → Sign In** now goes straight to the sign-in form. **Get Started** goes through onboarding to the sign-up form.

## Fixes

- **Reminders screen crash**: `useState` was called inside the list `.map()`, so completing a reminder or switching filters could crash with "Rendered fewer hooks than expected". Each card is now its own component.
- **Reminder due dates shifted a day** for users west of UTC: date-only values were parsed as UTC midnight. They are now saved at 9am local time.
- **Snoozing an overdue reminder** now moves it forward from today, not from the old due date (which could leave it still overdue).
- **Overdue badge stayed stale** after completing, snoozing, adding or deleting reminders until reload. Every reminders view now refreshes after any change.
- **Silent save failures**: adding or editing contacts, Quick Capture, adding reminders, interaction notes and profile edits went ahead as if successful even when the database rejected the write. They now show an error and keep what you typed.
- **Quick Capture back arrow** went Home instead of back to the previous screen.
- **Owner AI limits**: `generate-talking-points` and `generate-conversation-starters` compared the owner email case-sensitively against `Chicchori@…`, so the owner was rate-limited like everyone else. All owner checks are now case-insensitive. *(Edge functions must be redeployed.)*
- **Error log panel** (Ctrl+Shift+E) wrote console errors with `innerHTML`; now uses `textContent`.
- The list sort no longer mutates React state in place.

## Cleanup

- Removed 29 unreachable legacy files (old `App.tsx`, memories/events/search/settings screens, unused hooks and utils). They remain in git history.
- Removed debug `console.log` noise from navigation.
- `npm run typecheck` and `npm run lint` now pass with zero errors (previously 30+ type errors and 71 lint errors).

**Version**: 1.3.0
